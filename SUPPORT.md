# Getting help

- **Documentation**: start with [docs/README.md](docs/README.md).
- **Questions**: open a GitHub discussion, or an issue with the question template. Please include your version,
  how you run OpenDispatch (compose, Helm, from source) and what you have tried.
- **Bugs**: open an issue with the bug template.
- **Security problems**: never in public. See [SECURITY.md](SECURITY.md).
- **Commercial support and licensing**: email omni2@theomni-labs.com. See
  [COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md).

Community support is best effort. Maintainers answer issues and discussions when they can.
